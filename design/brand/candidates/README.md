# Кандидати знака

Варіанти, які варто пам'ятати, але які ще не стали знаком Relief.

- **F3 · Гантеля-рельєф** (`f3-dumbbell-relief-icon.svg`, `-mark.svg`): гантеля, диски якої спускаються сходинками, як тераси рельєфу; найбільші диски світяться `glow`. Найчитабельніша в малих розмірах і відразу каже «спорт». Відкладено 18.11.2026, поки шукаємо варіант із торсом і пресом.
