Чипи для вибору: в рядок (`.chips` + `.chipbtn`) або в анкеті — списком (`.qflow .chips.list`), сегментом чисел (`.chips.seg`) чи «таблетками» (`.chips.pills`).

**Що дає розробник:** кнопки `<button class="chipbtn" aria-pressed="true|false">` у контейнері `.chips`.

- У рядку вибраний чип — `accent-fill`. В анкеті вибраний варіант — `accent-soft` з рамкою 2 px `accent` і галочкою праворуч.
- Один варіант на рядок, коли текст довгий; сегмент — для 2–5 коротких значень (дні на тиждень).
