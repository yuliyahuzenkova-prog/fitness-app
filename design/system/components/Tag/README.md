Малі мітки `fs-12` 600: статус, тон і група м'язів. Одна форма (відступ 2 × 8, радіус 6), кілька тонів.

**Що дає розробник:** `<span class="tag [тон]">…</span>`; одне-два слова.

- **(без тону)** — акцент `accent-soft` / `accent-text`: «New», «Make it harder».
- **`neutral`** — `fill` / `ink`: пояснення без оцінки («each leg», рівень сили «Початковий»).
- **`good`** — `good-soft` / `good-text`: добре чи легше («Make it easier», рівень «Середній»).
- **`pr`** — `pr-soft` / `ink`: приклад і досягнення («Example», рівень «Сильний»; замість колишнього `.chip`).
- **`due`** — суцільний `accent-fill` / `accent-ink`: лише для того, що треба зробити зараз («Due»).
- Групи м'язів — `.mtag.push|pull|legs|core` (кольори `m-*` з текстом `ink`); колір не єдиний носій змісту — назва групи завжди написана.
- Мітка не кнопка: на дотик не реагує. Для вибору — `.chipbtn`, для досягнень — `Badge`. У рядку списку мітка під числами — `.tag.side` всередині `.list li`.
