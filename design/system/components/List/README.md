Список рядків «назва — значення» (`.list`) і пари «ключ — значення» (`.kv`).

**Що дає розробник:** `<ul class="list">` з `<li><span>…</span><span class="num">…</span></li>`.

- Роздільник — `line`; значення праворуч з `tabular-nums`.
- Формат тренування: `3 × 5 · 57.5 kg`.
- Довгий список (рекорди, історія) показує 5 найсвіжіших рядків; решта — за «Показати всі» / «Згорнути» (`.linkbtn`, ліворуч під списком). Кнопка з'являється лише коли рядків більше, ніж видно.
