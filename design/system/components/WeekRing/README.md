Картка тижня: кільце прогресу і сім днів.

**Що дає розробник:** `<div class="card weekcard">` з SVG `.ring` (`.trk` + `.val`, `stroke-dasharray` за часткою) і `.week` із 7 днів; класи дня: `on` (виконано), `plan` (заплановано), `today`, `mv` (рух без тренування).

- Кільце й виконані дні — `accent` / `accent-fill`; заплановані — контур `accent`.
- До заповнення профілю картки тижня немає: порожній тиждень нічого не каже, що робити, — це робить вітальна сцена (`HeroCard` `welcome`).
