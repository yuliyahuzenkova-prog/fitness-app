Сегментований перемикач для 2–4 взаємовиключних режимів (`.seg`), і широкий варіант для ракурсів 3D-фігури (`.seg.viewseg`).

**Що дає розробник:** `<div class="seg">` з кнопками `aria-pressed`.

- Звичайний: вибраний сегмент піднімається на `surface` з `shadow-seg`.
- `viewseg`: вибраний — `accent-soft` + `accent-text`, на всю ширину.
