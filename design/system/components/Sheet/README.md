Нижня шторка для деталей вправи, налаштувань і вибору мови.

**Що дає розробник:** `.sheet-bg` (затемнення) і `<div class="sheet" role="dialog">` з `.sheet-title` і вмістом; ручка зверху малюється сама.

- Верхні кути — `radius-sheet`, тло `surface`, максимальна висота — екран мінус 40 px.
- Закривається жестом вниз, тапом по затемненню і клавішею Esc.
