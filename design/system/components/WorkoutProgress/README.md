Прогрес тренування: скільки вправ і підходів виконано, і смуга з сегментом на кожну вправу.

**Що дає розробник:** `sessProgHtml(session)` — `<div class="sessprog">` прямою дитиною сторінки (не всередині секції, інакше не прилипне); `updateSessProg()` після кожної галочки.

- Прилипає під верхньою панеллю (`top: safe-area + 52px`), напівпрозора з розмиттям, як панель.
- Підписи — `label`, числа — 17 px 700 `tabular-nums`; сегменти — `fill`, заповнення — `accent`.
- Сегмент заповнюється часткою виконаних підходів вправи, тож видно, де ти зараз.
