Поля вводу, текстова область і чекбокс.

**Що дає розробник:** `<input>`, `<textarea>`, `<input type="checkbox">` з підписом.

- Шрифт 16 px (iOS не збільшує сторінку), заливка `fill`, радіус `radius-md`.
- У фокусі — рамка `accent`, тло `surface`.
- Чекбокс власний: 22 px, вибраний — `accent` з білою галочкою.
