Бейдж досягнення (milestone): «таблетка» 13 px з іконкою.

**Що дає розробник:** `<span class="badge [on]">` з `.ico` і назвою досягнення в контейнері `.badges`.

- Неотриманий — `fill` + `muted`; отриманий (`.on`) — `pr-soft`, іконка `pr`.
- Список починається з отриманих.
- На екрані «Прогрес» видно 3 останні отримані + 1 наступне, до якого людина йде. Решта — за посиланням «Показати всі» / «Згорнути» (`.linkbtn`, ліворуч під списком). Повний список — тільки на запит.
